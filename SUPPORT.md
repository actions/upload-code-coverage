# Support

## Issues and feature requests

Use [GitHub issues](https://github.com/actions/upload-code-coverage/issues) to
report bugs or request features. Search existing issues before opening a new
one to avoid duplicates.

Upload Code Coverage is under active development and maintained by GitHub
staff and the community. We will do our best to respond to issues and pull
requests in a timely manner.

For account-specific assistance or help with GitHub Code Quality, contact
[GitHub Support](https://support.github.com/).

For security vulnerabilities, follow the
[GitHub Actions security policy](https://github.com/actions/.github/blob/main/SECURITY.md).

## GitHub Support policy

Support for this project is limited to the resources listed above.
